# Task 2 - Exploratory Data Analysis (EDA)

## Overview
This project was completed as part of the ApexPlanet Data Analytics Internship (Task 2).

The objective of this project is to perform Exploratory Data Analysis (EDA) on a sales dataset using Python and SQL to discover patterns, trends, and business insights.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- SQL
- Jupyter Notebook

## Project Files
- Task2_EDA_ApexPlanet.ipynb – EDA notebook
- Task2_SQL.sql – SQL business queries
- sales_dataset.csv – Dataset used for analysis

## Analysis Performed
- Data loading and inspection
- Descriptive statistics
- Missing value analysis
- Data visualization
- Business insights using SQL
- Correlation analysis

## Visualizations
- Histogram
- Bar Chart
- Correlation Heatmap
